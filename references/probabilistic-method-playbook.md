# Probabilistic existence and construction

Use when a random object plus a bound on failures can establish the theorem. Specify the random space and show that avoiding the chosen bad events implies the exact target, including size or value requirements.

## Match the dependence structure

The displayed LLL criteria concern a finite bad-event family. Infinite constructions need a separate compactness or limiting argument.

| Situation | Kernel | Required obligation |
| --- | --- | --- |
| Total bad-event probability below one | Union bound | Sum of valid event-probability bounds is strictly below one |
| Violations are cheap to repair | Alteration | Repair all violations, bound total damage, and prevent newly created failures |
| Bounded local dependence | Symmetric LLL | Every event has probability at most `p`; a valid dependency graph has degree at most `d`; `e p (d+1) <= 1` |
| Unequal probabilities/degrees | Asymmetric LLL | Choose `0 < x_A < 1` with `Pr(A) <= x_A product_{B in Gamma(A)} (1-x_B)` |
| Ordinary graph is too dense | Lopsided LLL | Prove the required conditional-probability bound given avoidance of nonneighbors; overlap counts alone are insufficient |
| An algorithm is required | Product-space resampling or a justified resampling oracle | The resampling rule, termination bound, and event-detection cost match the constructive claim |

In an ordinary dependency graph, each event must be independent of the **sigma-field generated by all its nonneighbors**, not merely pairwise independent of each of them. Disjoint variable scopes in an independent product space establish this condition; hidden shared randomness can destroy it.

An LLL existence proof gives positive success probability. It does not by itself give efficient rejection sampling, a polynomial-time algorithm, or a deterministic construction. Under the standard product-space Moser-Tardos hypotheses, the resampling analysis must also account for witness parameters and the cost of finding a violated event.

## Diagnose a failed criterion

If probabilities are too large, change the distribution or use alteration. If degrees are too large, identify the actual random variables each event uses; remove dependencies only with a proof. Replacing an event by smaller events is useful only if they still cover failure and improve the resulting criterion. When a deterministic invariant or direct union bound already closes the theorem, no LLL machinery is needed.

For coloring or packing, derive event probabilities and overlap counts symbolically over the full parameter range. Check small sizes, high-degree vertices, and whether deletion creates new violations. Simulated resampling or finite overlap enumeration can test a construction but does not establish its universal hypotheses.

## Source map

- Erdos and Lovasz, *Problems and results on 3-chromatic hypergraphs and some related questions*: classical local-lemma framework.
- Moser and Tardos, *A constructive proof of the general Lovasz Local Lemma*: product-space resampling.
