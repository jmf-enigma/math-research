# Route by the missing implication

Use this index only when the next mathematical obligation is unclear. Select the domain that owns that obligation; a theorem's topic can differ from its proof mechanism.

| Missing implication | Reference | First question |
| --- | --- | --- |
| Candidate point/policy is globally optimal | [Optimization](optimization-or-playbook.md) | Which feasible dual bound, exchange, or convexity argument certifies it? |
| Bellman step preserves structure or verifies a policy | [Dynamic programming](dp-proof-playbook.md) | What function class is preserved, or what terminal term makes verification valid? |
| Local incentives imply all deviations | [Mechanism design](mechanism-design-playbook.md) | Does the domain permit an envelope argument, or are cycle inequalities required? |
| A response/rejection process yields equilibrium or stability | [Games and matching](games-matching-playbook.md) | Which fixed-point hypotheses or rejection invariant are actually available? |
| Sample-level control implies population/uniform control | [Learning theory](learning-theory-playbook.md) | Which probability, capacity, and dependence assumptions justify the upgrade? |
| One-step control sums to regret | [Bandits and online learning](bandits-oco-playbook.md) | Which confidence or potential inequality telescopes under the actual filtration? |
| Limited information forces loss | [Lower bounds](lower-bounds-playbook.md) | Which admissible instances demand different decisions but remain hard to distinguish? |
| Local failures can all be avoided | [Probabilistic method](probabilistic-method-playbook.md) | Are probabilities, repair costs, or dependencies small enough? |

If the obstacle is the representation itself, use [representation-witness.md](representation-witness.md). If a complete proof is dominated by calculations or cases, use [structural-proof-compression.md](structural-proof-compression.md). Named theorem families are search leads, not evidence that their hypotheses hold.
